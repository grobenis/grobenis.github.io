<div class="works-features">
<h3 class="works-features-title">功能亮点</h3>
<ul class="works-features-list">
<li><b>灵感工作台</b>多画板共享便签、独立摆放，资料库 / 分区 / 连线 / 印章 / 小地图，一键 PNG 导出</li>
<li><b>彩色贴纸</b>拖动、调大小、窗口置顶、换底色、调字号，自动保存</li>
<li><b>富文本 + 待办</b>加粗 / 高亮 / 代码 / 复选框，Markdown 导入导出，拖入 `.md` 直接成便签</li>
<li><b>管理与检索</b>标签筛选、搜索语法（`color:` / `tag:` / `before:`）、置顶、多选批量操作</li>
<li><b>到期提醒</b>系统通知，日历与编辑器可直接改期 / 延期 / 完成</li>
<li><b>统计页</b>日历热力图、勾选完成率、14 天趋势，点色块即跳回列表筛选</li>
<li><b>回收站 + 快照备份</b>误删可恢复，数据损坏自动保留现场</li>
<li><b>WebDAV 同步</b>坚果云 / Nextcloud 等，跨端合并不丢修改，密码加密存储</li>
</ul>
