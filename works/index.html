Nibs便签

跨平台桌面便签 · 彩色贴纸 + 管理窗口

多条彩色桌面贴纸随手贴、随手改，配一个清爽的管理窗口。Windows / Linux 用 Flutter 统一 UI，鸿蒙端用原生 ArkTS/ArkUI 重写，纯 JSON 本地存储、数据格式跨端一致，还能 WebDAV 同步。

FlutterDartArkTSArkUIWebDAV
下载安装包

功能亮点

  • 灵感工作台多画板共享便签、独立摆放，资料库 / 分区 / 连线 / 印章 / 小地图，一键 PNG 导出
  • 彩色贴纸拖动、调大小、窗口置顶、换底色、调字号，自动保存
  • 富文本 + 待办加粗 / 高亮 / 代码 / 复选框，Markdown 导入导出，拖入 `.md` 直接成便签
  • 管理与检索标签筛选、搜索语法（`color:` / `tag:` / `before:`）、置顶、多选批量操作
  • 到期提醒系统通知，日历与编辑器可直接改期 / 延期 / 完成
  • 统计页日历热力图、勾选完成率、14 天趋势，点色块即跳回列表筛选
  • 回收站 + 快照备份误删可恢复，数据损坏自动保留现场
  • WebDAV 同步坚果云 / Nextcloud 等，跨端合并不丢修改，密码加密存储
